# BASELINE — نظام الحضور والانصراف 3.6

> **تاريخ الأساس:** 2026-11-07 (Asia/Riyadh)
> **الحالة:** مكتمل محليًا ومُتحقق آليًا — لم يُنشر بعد على Apps Script حقيقي.

## 1) ما يعنيه هذا الملف

هذا هو خط الأساس (Baseline) للنسخة 3.6: الكود الذي اجتاز كل الاختبارات المحلية، والقيود المعروفة،
وطريقة إعادة إنتاج النتيجة. أي تغيير بعد هذا الأساس يجب أن يحافظ على اختبارات `npm test` و`npm run verify`.

## 2) البيئة الموثّقة

| المكوّن | القيمة |
|---|---|
| نظام التشغيل | Windows (PowerShell) |
| Node.js | 26.13.0 |
| npm | 11.20.0 (يُستدعى `npm.cmd`) |
| Git | 2.56.0.windows.4 |
| وقت التحقق | 2026-11-07، السبت، Asia/Riyadh |
| وقت التشغيل المستهدف | Google Apps Script V8 |
| قاعدة البيانات | Google Sheets |

حزم التطوير مثبّتة بإصدارات دقيقة في `package.json`: `esbuild 0.28.2`، `jsqr 1.4.0`،
`qrcode-generator 2.0.4`، `vitest 5.1.0`.

## 3) إعادة إنتاج التحقق

```powershell
npm.cmd install
npm.cmd run vendor   # يعيد بناء src/ui_Vendor.html من node_modules
npm.cmd run verify   # فحص ساكن: صياغة، include، عقد API/UI، غياب placeholders
npm.cmd test         # 73 اختبارًا في 9 ملفات
```

النتيجة المسجلة لهذا الأساس:

```
verify: OK — 13 server files, 7 UI files, 40 actions
Test Files  9 passed (9)
Tests       73 passed (73)
```

## 4) ما تم التحقق منه آليًا

- كل إجراء في `ACTION_POLICY_` له معالج واحد فقط، والواجهة لا تستدعي أي إجراء غير معلن.
- عقد الاستجابة الموحّد `{success, code, message, data, timestamp, requestId}`.
- رفض الطلبات المشوّهة، وانتهاء الجلسة، وفصل صلاحيات الأدوار، وحماية آخر مدير.
- الدخول بكلمة المرور وببطاقة QR وبـ Google، وقفل المحاولات، وتغيير كلمة المرور.
- إصدار البطاقات وإلغاؤها، وتجزئة الرموز، وترحيل رموز 3.5.
- تسجيل الحضور والانصراف، والتصحيح، وإنهاء اليوم، وثبات سجل اليوم المغلق.
- دورة الرحلة: فتح، مسح فردي، تراجع، تأكيد idempotent، إلغاء، وتعارضات الحالة.
- التقارير الثمانية، والنسخ الاحتياطي والاستعادة والاحتفاظ، وسجل التدقيق.
- بنية الأوراق والأعمدة، وعدم تسريب الأسرار أو بصمات البطاقات.

## 5) ما لا يمكن التحقق منه محليًا

هذه عناصر خارجية لا تخص منطق الكود، وتحتاج بيئة Google حقيقية:

- `clasp push` والنشر الفعلي (لا يوجد `scriptId`).
- سلوك كاميرا الهاتف وقارئ USB على أجهزة المدرسة.
- صلاحيات نطاق Google Workspace وسياسة `access: DOMAIN`.
- أداء Sheets الفعلي مع 60 طالبًا وسجل سنة كاملة.
- استعادة نسخة حقيقية من Drive.

تلك البنود مدرجة في `docs/OPERATIONS.md` كقائمة UAT قبل التسليم.

## 6) القيود المعروفة

- `bcryptjs` يعمل داخل V8 بتكلفة 12؛ كل اختبار مصادقة يستهلك ثواني. هذا مقصود لأمان كلمات المرور.
- لا تُستخدم `CacheService` كمرجع نهائي لأي قرار أمني؛ الجلسات والبطاقات تُقرأ من Script Properties/Sheets.
- الواجهة لا تستخدم `innerHTML` ولا `eval`؛ كل النصوص عبر `textContent` أو إنشاء DOM.
- `src/ui_Vendor.html` ملف مولّد (حوالي 149 ك.ب: jsQR + qrcode) ويُعاد بناؤه بـ `npm run vendor` عند تغيير الحزم.
- لا تُحذف سجلات الحضور التاريخية تلقائيًا، وفق سياسة `docs/RETENTION.md`.
